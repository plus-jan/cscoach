# Reports

Derived from the PureSkill.gg Competitive CS2 Gameplay Data Set (CSDS).
**Data provided by PureSkill.gg.**

Everything under `reports/` is derived data and is licensed **CC BY-NC-SA 4.0** (non-commercial,
attribution, share-alike), per the CSDS Data Subscriber Agreement (ADR-0008). The code in this repository
is MIT-licensed. Raw CSDS data and per-match tables are never committed.

- `data/`: export and corpus records (counts only, no match ids).
- `experiments/<timestamp>_<name>/`: reproducible experiment reports (CLAUDE.md "Evidence").
